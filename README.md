# My Task List

Name: Benny Wang

## Description
A simple task management web page.
You can add tasks, choose a priority (Low, Medium, High), mark tasks as completed,
and delete tasks.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser or use the link.
3. Add tasks using the form.

## Known Problems
- Tasks are not saved after the page is refreshed.
